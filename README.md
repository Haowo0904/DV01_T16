# DV01_T16

An interactive data visualisation project exploring non-fatal hospitalised road
crash injuries in Australia, 2011–2021, using BITRE's September 2023 release.

## Project structure

```text
index.html        Main page
css/style.css     Page styles
js/main.js        JavaScript entry point for future data loading and charts
data/             Source and processed datasets
assets/           Images, icons, and other static assets
```

Open `index.html` in a browser to view the starter page. No build step is required.
When data loading is added, serve the project through a local HTTP server.

The planned visualisations cover national trends, road user groups, changes
between two years, age distributions, and sex distributions. Datasets and charts
have not yet been added. Review source notes and reporting limitations before
publishing comparisons; case counts do not directly measure individual risk.

The `.gitkeep` files allow Git to track the initially empty data and assets folders.
