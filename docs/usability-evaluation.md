# Usability evaluation protocol and results template

Status: prepared; participant testing has not been conducted. Automated checks and developer review are not participant evidence.

## Method

Recruit five people representative of a general web audience, including people with differing data literacy and device preferences. Seek a keyboard-only session and, where feasible, an assistive-technology user. Obtain consent, use anonymous participant IDs, and avoid collecting health or identifying information. Run 15–20 minute moderated think-aloud sessions. Ask participants to explain their interpretation; do not teach the controls during a task. Record assistance separately from independent completion. Participants may stop at any time.

## Tasks and answer guide

| Task prompt | Success criteria |
| --- | --- |
| How did recorded national cases change between 2011 and 2021? | 34,033 to 39,505; +5,472 or approximately +16.1%; recognises this is recorded cases. |
| Which road user contributed the largest increase over that period? | Pedal cyclist, +2,772 cases. |
| Compare cyclist and motorcyclist national shares, then restore the starting view. | Uses measure and group controls; reset restores three groups and counts. |
| Compare changes from 2015 to 2021. | Changes both year controls and interprets the signed bars for that interval. |
| Find the largest recorded cyclist age band in 2021 and explain its percentage. | Matches the 2021 heatmap/table; denominator is all cyclist cases, not population. Moderator checks against displayed data. |
| Change the demographic year to 2011. What updated? | Both charts and findings update; recognises shared control. |
| Does a larger case count prove higher injury risk? How does a hatched cell differ from zero? | Recognises missing exposure/population denominator; no record is not zero. |

## Measures

Record task completion (independent / assisted / failed), elapsed seconds, errors, observed hesitation, and a 1–5 ease rating after each task. At the end ask: What was the main story? Which label or interaction was confusing? What would you change? Do not infer satisfaction from task completion alone.
