Hospitalised Road Crash Injuries

Exploring non-fatal hospitalised injuries associated with road traffic crashes.

About this project

This project will use BITRE's September 2023 data release to explore national trends, road user groups, changes between years, and age and sex distributions.

Interactive visualisations will be added as the project develops.

Understanding the data

Hospitalised injury cases are distinct from crashes and fatalities. Case counts alone do not measure individual injury risk; population size and travel exposure may differ between groups.
